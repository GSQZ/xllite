# 项目目录与维护约定

仓库只保留鸿蒙主工程本身；与本工程无关的附属项目和构建产物不随仓库分发，也不计入主应用进度。

## 主工程

| 路径 | 职责 |
| --- | --- |
| [entry/src/main/ets](../entry/src/main/ets/) | ArkTS 主源码；pages 页面、components 组件、services 会话与数据、theme 主题、utils 工具 |
| [entry/src/main/resources](../entry/src/main/resources/) | 图标、语言资源、路由与桌面卡片配置 |
| [AppScope](../AppScope/) | 应用级标识和资源 |
| [hvigor](../hvigor/) | 构建器版本配置 |
| [tools](../tools/) | 可复用构建、模拟器、行为回归与配色检查 |
| [docs](./) | 契约文档、平台边界与专题验收记录 |
| [.wolf](../.wolf/) | 工具链依赖的基线数据（警告基线、构建输入指纹、对比度基准），供回归脚本读取 |

正式入口路由以 [main_pages.json](../entry/src/main/resources/base/profile/main_pages.json) 为准。

## 已移出版本库的内容

以下内容与鸿蒙主工程无依赖关系，不随本仓库分发，本机仍保留：

- 计算机网络刷题站（独立静态 PWA）与火山引擎 AI 中转站（独立 Node / Express / MySQL 服务）：均为独立项目，不是校园 API 后端。
- 根目录历史单文件刷题页面与旧实施报告：历史归档，不与主应用进度合并计数。
- 开发过程材料不随主工程分发，只保留与实现、构建、验证直接相关的文档。
- 模拟器验收产出的解包 HAP、`.abc` 字节码、sourceMap 与 hilog 转储：体积大且可由构建复现。

## 本地内容与产物

SDK 工具链目录、签名证书、SDK 本地路径、环境变量、缓存、构建包和验收截图均留在原位且受忽略规则约束。

- 日常修改仅在当前主工程，英文构建目录只是同步快照，不反向覆盖源码。
- 构建目录须为独立真实 ASCII 路径，构建器会解析联接，因此此类临时构建副本不使用 junction。
- 通用 HAP 输出可能被后续构建覆盖，使用同轮输入哈希与包哈希判定对应版本。

## Git 约定

- `main` 分支是 Flutter 实现，与本工程无共同提交历史，永不改动；鸿蒙实现全部提交在 `harmony` 分支。
- 本地私密配置、签名材料、环境变量不入库；现有忽略规则保留并补充通用依赖缓存规则。
- 使用仓库级行尾约定：源码 LF，PowerShell / Windows 批处理 CRLF；不做无关全树重格式化。
- 维护当前结论时更新 [更新日志](../CHANGELOG.md)，旧报告保留日期与快照身份，不用旧截图代替新源码验收。
