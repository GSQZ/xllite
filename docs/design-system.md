# 新理Lite 设计规范 v1.0

> 适用范围：新理Lite 1.0.0 起的全部 Flutter 页面。
> 代码落地：`lib/shared/theme/`（令牌与主题）、`lib/shared/widgets/`（通用组件与动效）。
> 原则上页面里**不写裸数值**：颜色、字号、间距、圆角、时长、曲线一律取自本规范对应的令牌。

---

## 1. 设计原则

| 原则 | 含义 | 反例 |
| --- | --- | --- |
| **清爽克制** | 一屏只有一个主操作；装饰只做氛围，不抢内容 | 大面积插画、营销口号、为分组而分组的卡片 |
| **表单优先** | 输入、提交、纠错的路径最短、反馈最快 | 整页 loading 替换表单；报错后清空输入 |
| **状态完整** | 正常 / 聚焦 / 禁用 / 加载 / 失败 / 成功都有明确样式和恢复路径 | 只有成功态；失败只弹一次 Toast |
| **动效有意义** | 动画只用来说明"发生了什么、从哪来、到哪去" | 无限循环的装饰动画；超过 0.5s 的转场 |
| **人人可用** | 适配小屏、键盘、安全区、2 倍字号、读屏、减少动态效果 | 固定高度布局；无标签的图标按钮 |
| **诚实** | 明确"民间开发版本"；不虚构链接和能力 | 仿学校官方标识；写"密码仅在本机处理" |

## 2. 色彩

### 2.1 品牌色与皮肤

默认皮肤是 `#1D6FD8` 校园蓝（`AppColors.seed` / `ThemeSkin.campusBlue`），共十款皮肤可选，见 §11.20。

| 令牌 | 值 | 说明 |
| --- | --- | --- |
| `ThemeSkin.color` | 每款一个色 | 生成整套配色的种子；浅色模式下直接作为 `primary`（与白字对比度 ≥ 3:1，正文按钮为 16sp 半粗） |
| `ThemeSkin.glow` | 每款两个色（浅 / 深） | 首页与登录页背景氛围色的染色 |

配色由 `ColorScheme.fromSeed(seed, DynamicSchemeVariant.fidelity)` 生成，深色模式自动推导。
浅色模式把生成出的偏深藏青 `primary` 替换为种子色本身，观感更轻快。

### 2.2 语义角色（取 `Theme.of(context).colorScheme`）

| 角色 | 用途 |
| --- | --- |
| `primary` / `onPrimary` | 主按钮、焦点环、链接、品牌标识 |
| `surface` | 页面底色 |
| `surfaceContainerHigh`（浅色 72% 透明度） | 输入框填充 |
| `surfaceContainerLowest` / 深色 `surfaceContainerLow` | 次要按钮底色 |
| `onSurface` | 正文、标题 |
| `onSurfaceVariant` | 辅助说明、标签、图标、免责声明 |
| `outlineVariant` | 分割线、次要按钮描边 |
| `error` / `errorContainer` / `onErrorContainer` | 校验错误、失败提示 |

### 2.3 状态色扩展（`StatusColors.of(context)`）

| 令牌 | 浅色 | 深色 | 用途 |
| --- | --- | --- | --- |
| `warning` | `#8A5A00` | `#FFC65C` | 倒计时临近过期 |
| `warningContainer` / `onWarningContainer` | `#FFF1D1` / `#4A3000` | `#4A3410` / `#FFE2A8` | 网络波动、登录态未刷新等**不阻断**提示 |
| `success` | `#1B7F4B` | `#7DDBA3` | 微信入口图标点缀、成功图标 |
| `successContainer` / `onSuccessContainer` | `#D9F5E3` / `#00391D` | `#0F4D2C` / `#B9F2CD` | 登录成功徽章 |

### 2.4 功能入口色（`EntryHue`）

首页入口图标专用，只用于图标本身和 12%（深色 22%）透明度的图标底，**不用于文字**。

| 入口 | 色相 | 浅色 | 深色 |
| --- | --- | --- | --- |
| 成绩 | `blue` | `#1D6FD8` | `#8AB4FF` |
| 考试 | `indigo` | `#5B5BD6` | `#B2B0FF` |
| 校园卡 | `teal` | `#0B8586` | `#6FD6D2` |
| 宿舍电量 | `amber` | `#B86E00` | `#FFC266` |

### 2.5 用色规则

- 一个视图里**只有一个**实心 `primary` 按钮。
- 错误用红（阻断，需要用户处理）；警告用琥珀（不阻断，系统会自动重试或仍可使用）。
- 第三方服务只做**点缀色提示**（微信入口图标为绿色），不使用第三方商标图形。
- 正文对比度 ≥ 4.5:1，大字与图标 ≥ 3:1；组件测试中以 `textContrastGuideline` 校验。

## 3. 字体与排版

使用系统字体（iOS 苹方 / Android 思源黑体 & Roboto），不额外打包字体。

| 样式 | 字号 / 字重 / 行高 | 用途 |
| --- | --- | --- |
| 欢迎标题（登录页专用） | 28（小屏 24）/ w700 / 字距 0.2 | 入口页主标题 |
| `headlineSmall` | 26 / w600 / 1.3 | 状态页大标题（"已登录"） |
| `titleLarge` | 20 / w600 / 1.35 | 状态面板标题 |
| `titleMedium` | 17 / w600 / 1.4 | 顶栏标题、分节标题 |
| `titleSmall` | 15 / w600 / 1.4 | 提示条标题 |
| `bodyLarge` | 16 / 1.5 | 输入文字、副标题 |
| `bodyMedium` | 14 / 1.5 | 正文、说明 |
| `bodySmall` | 12 / 1.5 | 免责声明、辅助信息 |
| `labelLarge` | 16 / w600 / 1.25 | 按钮文字 |

规则：

- 系统字号放大**最高跟随到 2.0 倍**（`MediaQuery.withClampedTextScaling`），所有页面必须在 320×568 + 2 倍字号下可滚动、不溢出。
- 产品名"新理Lite"不得被断行拆开；需要换行时整体换行（见登录页标题实现）。
- 数字倒计时使用等宽数字 `FontFeature.tabularFigures()`，避免跳动。
- 中文句末不加多余标点的短句用于按钮与提示条标题；完整说明句保留标点。

## 4. 间距与布局

### 4.1 间距（4pt 体系，`AppSpacing`）

| 令牌 | 值 | 常见用途 |
| --- | --- | --- |
| `xs` | 4 | 图标与文字微调 |
| `sm` | 8 | 标题与副标题 |
| `md` | 12 | 两个输入框之间（+2 = 14） |
| `lg` | 16 | 组件内边距、分组之间 |
| `xl` | 24 | 区块之间、页面左右边距 |
| `xxl` | 32 | 大区块之间 |
| `xxxl` | 48 | 页面顶部留白上限 |

### 4.2 页面布局

- Android 手机在 Activity 内使用独立密度配置，竖屏以 iPhone 17 Pro 的 402 逻辑像素宽度为基准；DPI 按窗口短边的实际像素计算，横屏沿用短边比例。仅作用于 App 页面，不修改系统显示密度或桌面小组件。系统字体缩放保留；平板（最小宽度 ≥ 600dp）与窄分屏窗口（宽度 < 240dp）沿用系统密度。
- 页面左右边距：宽度 ≥ 360 用 24，窄屏用 16（`AppSpacing.gutterFor`）。
- 表单内容最大宽度 440（`AppSizes.contentMaxWidth`），平板 / 横屏居中。
- 入口类页面使用 `AdaptivePageBody`：`header` 顶部、`footer` 底部，内容超出可视区（键盘、放大字号）时整体滚动；拖动时收起键盘。
- 高屏顶部预留 5% 屏高（≤ 48）的呼吸空间；屏高 < 700 时取消该留白，品牌标识缩小到 48。
- 所有页面包在 `SafeArea` 中；底部固定区域需要处理底部安全区。

## 5. 形状与层级

| 令牌 | 值 | 用途 |
| --- | --- | --- |
| `AppRadius.sm` | 8 | 文字按钮 |
| `AppRadius.md` | 12 | 提示条、SnackBar |
| `AppRadius.control` | 14 | 输入框、整行按钮 |
| `AppRadius.lg` | 16 | 预留：列表卡片 |
| `AppRadius.xl` | 24 | 对话框 |
| 品牌标识 | 边长 × 0.3 | 应用标识圆角 |

层级只用**彩色柔光**表达，不使用灰黑投影：

| 元素 | 阴影 |
| --- | --- |
| 主按钮（可用 / 加载中） | `primary` 26%，模糊 18，Y 偏移 6；按下时 18% / 10 / 3 |
| 主按钮（禁用） | 无 |
| 品牌标识 | `primary` 28%，模糊 0.4×边长，Y 偏移 0.14×边长 |
| 首页课程主卡 | `primary` 24%，模糊 28，Y 偏移 12 |

背景氛围统一使用 `SoftBackdrop`：顶部 `primary` 11%（深色 14%）渐隐到约 57% 屏高，右上一处主光晕、左侧一处弱光晕；不响应触摸、对读屏隐藏。

**背景只有一份**：由 `AuthGate` 持有，启动页、登录页、首页（含三个 tab）共用同一个背景，各页面的 `Scaffold` 背景透明。所以页面切换时背景纹丝不动，只有内容在变。推入的二级页面（扫码页、开发中页面等）使用自己的不透明背景。

## 6. 组件规范

### 6.1 按钮 `AppButton`

| 变体 | 外观 | 用途 |
| --- | --- | --- |
| `filled` | `primary` 实心 + 彩色柔光 | 页面唯一主操作（登录、重新获取二维码） |
| `outlined` | 浅底 + `outlineVariant` 描边 + `onSurface` 文字 | 次要操作（微信扫码登录、改用账号密码登录） |
| `destructive: true` | 文字 / 描边改为 `error` | 退出登录 |

- 尺寸：高 54、整行宽、圆角 14、左右内边距 24；图标 20，图文间距 10。
- 状态：

| 状态 | 表现 |
| --- | --- |
| 正常 | 如上 |
| 按下 | 缩放到 0.98（150ms），柔光收紧 |
| 加载中 | 保留原色（78% 透明度），18px 进度圈 + 进行时文案（"正在登录…"）；不可点击 |
| 禁用 | Material 默认禁用色，无柔光，图标点缀色失效 |

- 文案与加载态之间交叉淡入 + 0.92→1 缩放（250ms）。

### 6.2 输入框（主题 + `SoftInputBorder`）

- 高约 56，圆角 14，**无描边填充式**；标签在框内上浮，不切割边框。
- 状态：

| 状态 | 表现 |
| --- | --- |
| 正常 | 填充色、无边框、前缀图标 `onSurfaceVariant` |
| 聚焦 | 1.6px `primary` 圆角描边，标签与前缀图标变 `primary` |
| 错误 | 1.2px 红色描边（聚焦时 1.6px），下方错误文字最多 3 行 |
| 禁用 | 填充色保留，文字与图标降为 38% |

- 必须配置：`autofillHints`、`textInputAction`（下一项 / 完成）、`autocorrect: false`。密码框额外配置显隐按钮（带"显示密码 / 隐藏密码"提示）。
- 密码只校验非空，**不 trim**。

### 6.3 提示条 `StatusBanner`

| 色调 | 场景 | 是否可关闭 |
| --- | --- | --- |
| `error` | 表单提交失败、退出未完成 | 否（用户修改输入后自动消失） |
| `warning` | 网络波动自动重试、登录态未刷新、恢复登录失败 | 是 |
| `info` | 一般说明 | 视情况 |

可带一个文字操作（"重试""重试退出"），操作进行中显示小进度圈并禁用。整体为 `liveRegion`，读屏会主动播报。

### 6.4 状态面板 `StatePanel`

全区域的加载 / 空 / 失败状态：64px 圆形图标底 + 标题 + 说明 + 1～2 个整行按钮，内容居中、可滚动。失败面板必须提供至少一个恢复操作。

### 6.5 品牌标识 `BrandMark`

- 使用 `main` 分支沿用的青绿色纸飞机、书本与金色星点标识：`assets/branding/xinli_lite_app_icon_1024.png`，与 iOS / Android 桌面图标一致。保留原图颜色，以圆角裁切和轻柔中性阴影融入页面，不随皮肤染色。
- 标准尺寸：登录页 56（小屏 48）、启动页 56。
- **禁止**使用或模仿学校校徽、校名标准字。

使用 Flutter 内置 Material Icons，不引入第三方图标库。

## 8. 动效规范

### 8.1 原则

**页面交接的三条规则**（所有整屏切换都遵守）：

1. **旧页面只负责退场，而且要快**：约 200ms，加速淡出，并轻微缩小到 97.5%，像是"退到后面"。
2. **新页面立即就位，自己编排入场**：外层不再给它整体做淡入，内容只淡入一次，不会发虚或迟到。
3. **入场延迟 120ms 开始**：这时旧页面已经淡掉大半，两者只在尾巴上轻微重叠，**中间不会出现只剩背景的空白**。


1. **有因果**：每个动画对应一次状态变化（出现、离开、确认、拒绝），不做无目的的循环装饰。
2. **快进慢出**：出现用减速曲线，离开用加速曲线，且离开比出现更快、更轻。
3. **短**：单个动效 ≤ 400ms，整屏入场 ≤ 700ms；用户操作的反馈 ≤ 150ms 起效。
4. **只动 transform 和 opacity**：不对布局尺寸做逐帧动画（`AnimatedSize` 除外，仅用于提示条展开）。
5. **尊重系统设置**：开启"减少动态效果 / 移除动画"时，所有位移、缩放、抖动关闭，时长归零；触感反馈保留。
6. **不打断输入**：动画期间控件始终可交互（加载锁定除外），不因动画延迟提交。

### 8.2 动效令牌（`AppMotion`）

| 令牌 | 值 | 用途 |
| --- | --- | --- |
| `short` | 150ms | 按压缩放、图标切换 |
| `medium` | 250ms | 按钮文案切换、提示条出现、进度条显隐 |
| `long` | 400ms | 整屏切换（登录 ↔ 已登录）、扫码页状态切换 |
| `entrance` | 700ms | 登录页错峰入场、上课进度条过渡 |
| `handoff` | 420ms | 启动 / 登录 / 首页之间的交接；旧页面在前 50%（210ms）内退场 |
| `entranceDelay` | 120ms | 新页面开始入场前的等待，正好接上旧页面退场的尾巴 |
| `homeEntrance` | 820ms | 首页错峰入场 |
| `tabSwitch` | 300ms | 底部 tab 淡出淡入 |
| `countUp` | 900ms | 余额、电量数字从 0 滚动到实际值 |
| `shake` | 420ms | 登录被拒绝的表单抖动 |
| `curve` | `easeOutCubic` | 出现 |
| `exit` | `easeInCubic` | 离开 |
| `emphasized` | `easeInOutCubicEmphasized` | 停留在屏上的形变（提示条展开 / 收起） |
| `pop` | `easeOutBack` | 庆祝性弹出（仅成功徽章） |
| `AppMotion.reduced(context)` | — | 是否开启了减少动态效果 |

### 8.3 动效清单

| # | 场景 | 实现 | 参数 |
| --- | --- | --- | --- |
| 1 | **登录页错峰入场** | `StaggeredReveal` | 等待 120ms 后，品牌区 → 表单 → 登录按钮 → 其他方式 → 免责声明，间隔 56ms；每段约 315ms 淡入 + 上移 14px；`easeOutCubic` |
| 2 | **按钮按压** | `AppButton` 内 `AnimatedScale` | 按下缩到 0.98，柔光收紧，150ms |
| 3 | **按钮文案 ↔ 加载** | `AnimatedSwitcher` | 交叉淡入 + 0.92→1 缩放，250ms |
| 4 | **登录被拒 / 必填为空** | `ShakeTransition` + `HapticFeedback.mediumImpact` | 水平 3 次衰减摆动，振幅 8px，420ms，结束精确归零 |
| 5 | **错误提示条** | `AnimatedSize` + `AnimatedSwitcher(fadeThrough)` | 高度 250ms `emphasized` 展开，内容淡入 + 0.985→1 缩放；修改输入后同样收起 |
| 6 | **密码显隐图标** | `AnimatedSwitcher` | 150ms 交叉淡入 |
| 7 | **输入框聚焦** | Material `InputDecorator` 内置 | 描边颜色 / 标签上浮动画 |
| 8 | **启动恢复页** | `RestoringPage` | 品牌 0～400ms 淡入 + 0.92→1 缩放；进度提示在 500ms 后才淡入，**快速恢复时不会闪出转圈** |
| 9 | **整屏交接**（启动 / 登录 / 首页） | `AuthGate` 的 `AnimatedSwitcher` + `handoffTransition` | 旧页面 210ms 内加速淡出并缩小到 97.5%；新页面不做外层淡入，由自己的错峰入场在 120ms 后接上。背景始终不动 |
| 10 | **推入扫码页** | `PageTransitionsTheme` | Android：`FadeForwardsPageTransitionsBuilder`；iOS：Cupertino（全屏弹窗自下而上） |
| 11 | **扫码页状态切换**（获取中 / 二维码 / 失败 / 过期） | `AnimatedSwitcher` + `fadeThroughTransition` | 400ms |
| 12 | **授权页加载进度条** | `AnimatedOpacity` | 250ms 淡出；隐藏时自动转为静止，不在后台持续动画 |

### 8.4 容器展开转场（Container Transform）

从首页进入成绩、考试、校园卡，使用"点哪里，哪里放大进入"：

1. **起点就是被点的元素**：容器从该元素的实际位置、尺寸、圆角和底色出发，用 500ms `emphasized` 曲线长到全屏，圆角收为 0，底色过渡到页面背景。
2. **内容交接在早期完成**：元素原本的内容在前 22% 内淡出；目标页面按全屏尺寸排版，再等比缩放到容器宽度，在 12%～55% 之间淡入。因此任何时刻都不会出现被拉伸变形的文字。
3. **层次**：容器飞行途中带一层阴影（中段最深）；后方页面加 16% 的暗色遮罩。
4. **原元素隐藏**：页面打开期间原元素透明但保留位置，关闭时容器缩回它当前所在的位置，结束瞬间与原元素完全重合，看不出接缝。
5. **关闭**：420ms，曲线镜像，先快后慢地"落回"原元素。
6. **iOS 边缘右滑返回**：手指从左边缘拖动时，页面跟随手指缩回原元素；松手后，滑过约 40% 或快速甩动就关闭，否则弹回。Android 使用系统返回。
7. **减少动态效果**：退化为简单淡入淡出。

### 8.5 触感反馈

| 时机 | 反馈 |
| --- | --- |
| 登录被拒、必填为空 | `HapticFeedback.mediumImpact()` |
| 切换底部 tab | `HapticFeedback.selectionClick()` |
| 其他 | 暂不添加；后续只在"确认 / 拒绝"类关键节点使用，不用于普通点击 |

### 8.6 性能与工程约束

- 动画控制器在 `State` 中创建、在 `dispose` 中释放；`build()` 里只用 `animation.drive(CurveTween(...))`（不注册监听，避免泄漏），不在 `build()` 中 `new CurvedAnimation`。
- 禁止无限循环的装饰动画（会耗电，也会让 `pumpAndSettle` 永远无法结束）。系统转圈只在真实等待时出现。
- 不可见的进度条必须是确定态（`value != null`），避免隐藏后仍在逐帧重绘。
- 列表和长页面里的入场动画只播放一次，不在滚动复用时重复播放。
- 退出登录时业务层会立即清空数据，但首页还在淡出。页面通过 `SignedInMemo` 读取"最后一次登录态下的数据"，淡出过程中内容保持不变，不会闪成空白或加载态。
- 嵌套 `TickerMode` 必须放在淡出动画**内部**，否则会连同淡出动画一起暂停，导致隐藏页面残留在屏幕上。

### 8.7 关于动画依赖库

本期**不引入**动画库（如 `flutter_animate`、`lottie`、`rive`、`animations`），容器展开转场也是自行实现的。理由：

- 上述 15 项动效用 Flutter 内置能力即可实现，且已统一收口在 `AppMotion` 和 `lib/shared/widgets/motion.dart`；
- 少一个依赖就少一份升级和平台兼容风险，组件测试的时序也更可控（已有 `motion_test.dart` 覆盖抖动、触感和减少动态效果）。

可以考虑引入的时机：

| 库 | 适用场景 | 前提 |
| --- | --- | --- |
| `flutter_animate` | 业务页面出现大量链式 / 组合动效，内置写法明显冗长 | 仍须遵守本规范的时长与曲线令牌，并支持减少动态效果 |
| `lottie` / `rive` | 空状态、引导页需要插画动画 | 有设计师产出的正式素材；单个文件 ≤ 100KB；提供静态降级帧 |

## 9. 无障碍要求（验收项）

- 触控目标 ≥ 48×48（`androidTapTargetGuideline` / `iOSTapTargetGuideline`）。
- 所有可点击元素有标签（`labeledTapTargetGuideline`）。

- 错误、警告、加载结论使用 `liveRegion` 播报；页面标题使用 `Semantics(header: true)`。
- 开启"减少动态效果"后无位移、缩放、抖动。

## 10. 文案规范

- 语气：简洁、平实、直接给出下一步。例："学号或密码错误，请检查后重试"，不说"哎呀出错啦"。
- 进行时以"正在…"开头并带省略号："正在登录…""正在确认登录…"。

- 必须出现：**"民间开发版本，不代表学校官方应用"**。
- 密码说明只能写："密码经服务端转交学校认证，客户端仅保存登录令牌"。**不得**写"密码仅在本机处理"。
- 不虚构注册、找回密码、隐私政策链接或验证码流程。
- 不展示、复制、输出 accessToken。

  3. 一行状态：加载中为转圈 +"正在获取付款码…"；就绪为倒计时环 +"N 秒后刷新 · 余额 ¥x" +"刷新"；失败为原因 +"重试"。

**支付成功（余额推断）**

学校系统没有支付结果接口，因此采用推断，并如实告知这是推断：

1. 弹层打开后第一条余额作为基线，之后每 3 秒重查余额（2 分钟后放缓到 6 秒，10 分钟后停止）。只在弹层打开且 App 在前台时进行。
2. 余额下降 ≥ 0.01 元即判定为一笔消费，金额为差额；余额上升（退款、充值）只移动基线，不判定为消费。
3. 判定成立后立即收起付款码凭证，并刷新一次交易流水，用金额匹配最近几条流水，取到商户名后补进成功页。
4. 成功页在原二维码位置原地替换（弹层高度不变）：绿色圆盘弹入 → 对勾自绘 → 光环与火花扩散 → 金额滚动 → 商户名与余额落定 → "完成"；标题同时变为"已完成支付"。
5. 这是启发式判断：用户在别处同时消费也可能被识别为本次支付；学校余额更新延迟时也可能漏判。成功后立即刷新余额与流水，金额以学校系统为准。

- 星期条：七天一列，显示星期、日期、当天节数的圆点（最多三点）；今天用主色描边，选中项填充主色。
- 下面是当天时间轴：左侧时间（开始 / 结束），右侧课程卡，卡片左侧 4px 课程色条；进行中的课描边加重、显示进度条和"进行中"标签；已结束的课降低透明度；无法确定时间的课程显示"时间待定"。
- 校历的停课 / 调课在这里体现：调课日提示"按 x 月 x 日的课表上课"，停课日显示"今日停课"；学期未开始显示"尚未开课"。
- 空状态："这天没有课"。

**周视图**
- 参考旧版紧凑网格：普通字号下完整显示 5 个工作日，周末有课则显示 7 天；大字体、窄屏或冲突课程确实放不下时横向滚动。
- 独立纯色表格底，圆角 14px，细网格线；每小节 50px，午休和晚间间隔增加留白。课程块使用不透明的柔和底色，网格线不穿过课程卡片。
- 同一时段冲突课程分列，同一天其他时段占满列宽。课程名 11.5px / 1.3 行高，地点 10.5px；二者跟随系统字体，不通过缩放强塞文字。
- 地点优先提取真实教室号：`【10号实验楼】软件开发实验室【10#414】` → `10#414`，`【工科实训楼】…【工科实训楼403室】` → `实训403`，`【1号教学楼】JT1204` → `JT1204`。完整地点在课程详情保留。
- 横向滚动视口覆盖整个屏幕，12px 起始留白放在滚动内容内，课程滑到屏幕边缘再离开；不能在页面内边距处突兀裁切。
- 纵向内容位于系统状态栏安全区之下；今天所在列有淡色底，进行中的课程描边，当前时间显示红线。
- 无法确定时间的课程在网格下方提示，可切到「当日」查看。

当日视图支持左右滑动切换上一天 / 下一天，也可点日期条切换。周视图左右滑动用于查看完整网格，上一周 / 下一周使用顶部箭头切换。切换共 460ms，**分两段而不是交叉淡化**：前 40% 旧视图完全淡出，后 60% 新视图淡入并按切换方向轻微平移。两段不重叠，避免两天的卡片同时半透明、旧内容从新卡片缝隙里透出来形成残影。点任意课程弹出详情（时间、地点、节次、周次、教师）。没有校历时两个视图都退回按星期排列，并在页面上说明未按教学周筛选。

### 11.13 宿舍电费（顶部弹层）

- 首页"宿舍电量"入口打开与付款码相同的顶部弹层，不进二级页面。弹层内三个视图原地切换：**电量**（强调面板：宿舍、剩余电量、偏低提示、"充值电费""更换宿舍"）、**设置 / 更换宿舍**（输入框 +"查询电量"）、**充值电费**（见 11.14）。
- 未设置宿舍时直接打开在"设置宿舍"视图。刷新时只在面板角上出现小转圈。

### 11.14 充值（顶部弹层，一卡通 / 电费共用）

- 校园卡页"充值"按钮打开顶部弹层；电费充值在电费弹层内进入。没有二级页面，也没有单独的核对页。
- 弹层内分步原地切换（高度平滑变化，内容按方向滑入）：
  1. **填写**：充值对象与余额 / 电量摘要卡；金额卡片（电费显示约合度数）与"其他金额"；支付方式列表（微信、支付宝使用对应品牌标志，校园卡余额使用钱包图标）；按需展开的支付密码；"下一步 · ¥x"。
  2. **确认**：大号金额、充值对象、支付方式、预计电量；"确认支付"（提交中显示"正在提交…"，弹层不可关闭）、左上角返回修改。
  3. **成功**：电费余额支付成功时播放支付成功动效；本人校园卡外部支付后，余额增加达到充值金额时显示"充值已到账"。
  4. **等待到账**：外部支付返回或结果未知时显示，提供"继续支付"和"完成"，不显示任何成功字样。
- 上一笔充值未确认到账时（包括重启后），填写步骤顶部显示提示条，需点"已到账，开始新充值"后才能再次充值。
- 弹层在键盘弹出时自动缩到键盘上方。

### 11.15 学校收银台

- 唯一保留的整页：学校收银网页必须以完整页面加载。顶栏为关闭按钮与"学校收银台"，底部常驻"付款完成后返回核对"说明栏；无法打开时显示状态面板。

### 11.16 毛玻璃

- 所有卡片（列表分组、首页入口、课程卡、"我的"分组、充值金额卡等）、底部导航栏、二级页面标题栏和顶部弹层都使用毛玻璃：背后内容模糊（σ 18）+ 半透明底色 + 细亮边。
- 卡片在同一页面 / 弹层内共享一次模糊采样（`BackdropGroup`），控制低端机开销；导航栏、标题栏、弹层单独模糊，保证滚动到其下方的内容被真实模糊。
- 二级页面标题栏静止时透明；内容上滑的前约 28px 内，模糊、底色和分隔线随滚动距离逐渐出现，不再瞬间出现。
- 首页内容延伸到导航栏下方，列表底部留出导航栏高度。

### 11.17 视图切换规则

`AnimatedSwitcher` 只在子组件加入时调用一次 `transitionBuilder`，因此过渡必须返回**监听动画**的组件（`FadeTransition`、`AnimatedBuilder` 等），不能在构建时直接读取 `animation.value`，否则新视图会停在当时的透明度（常为 0，表现为空白）。所有顺序切换统一使用 `sequentialTransition`：旧视图在前 35% 完全淡出，新视图随后淡入并按方向滑入。

### 11.18 输入：自绘键盘

- **除登录页外，任何输入都不拉起系统键盘**，一律使用应用内自绘键盘（`DrawnKeypad`，3×4：1–9、特殊键、0、删除；长按删除清空；每次按键有轻触感，非法按键有重触感并被拒绝）。
- 宿舍号：大号数字显示 + 闪烁光标，特殊键为"#"（不能打头、只能一个），格式为"楼号#房间号"；旧格式"5号楼524"自动转为"5#524"。外接键盘仍可输入。
- 金额：`DrawnField` 显示 + 小数点键；最多 5 位整数、2 位小数、不允许前导 0。选择预设金额时自动收起键盘。
- 对方学号：`DrawnField` + 纯数字键盘。
- 一卡通支付密码：**6 格密码框**（`PinCells`），每输入一位，对应格子弹出一个圆点；下一格高亮并显示光标；输满 6 位自动收起键盘；不足 6 位提示"请输入 6 位支付密码"。数字从不显示。
- 同一时间只展开一个键盘，键盘在对应输入框下方平滑展开。

### 11.19 充值到账判断

- "充值前"的余额与流水，取自与轮询**同一个**余额查询和交易记录（打开弹层和确认支付前都会刷新），不使用充值配置里的余额。
- 两个独立信号任一成立即判定到账：主账户余额增加 ≥ 充值金额；或出现一笔充值前没有的、金额相同的新流水。
- 轮询：前 2 分钟每 3 秒，之后每 8 秒，10 分钟后停止。等待页实时显示"当前余额"，并始终提供"已到账"（手动确认、解除锁定）与"稍后再看"。

### 11.20 主题与外观（皮肤 + 明暗模式）

- 入口："我的 → 主题与外观"（右侧始终贴着箭头显示当前皮肤名和色点，`Expanded` 标签吃掉空白，右侧内容就不会飘到中间）。
- 十款皮肤，每款一个色 + 一层背景氛围色：校园蓝（默认）、湖青、松绿、暮紫、胭脂、赭橙、咖啡、石墨、墨黑、素白。
- 明暗模式：**跟随系统 / 浅色 / 深色** 三选一，默认跟随系统。使用与课表视图共用的 `AppSegmented`，与色板同属一个弹层。
- 弹层结构：毛玻璃顶部弹层 → 标题"主题与外观" → 皮肤预览卡 → 色板 → "外观"分段控件 → 说明 → "恢复默认皮肤"。
- 预览卡是一次真实绘制：固定设计尺寸 340 × 156，用 `FittedBox(BoxFit.contain)` 缩放到弹层宽度，并把文字缩放钳制为 1，因此 2 倍字体下形状也完全一致。卡内展示背景氛围、一个余额数字、两枚胶囊标签和两个按钮——**所有胶囊与按钮同为 26pt 高、14pt 内边距**，两行对齐。
- 色板：3 列自适应 `Wrap`，每格 46pt 圆点 + 选中描边与光晕 + 勾选（`AnimatedScale` + `AppMotion.pop`），下方是皮肤名。选中即生效，`HapticFeedback.selectionClick`。
- 皮肤同时驱动：Material 配色（种子色，浅色下主色即种子色）、首页 / 登录页背景氛围色、首页屏幕小组件的强调色。切换时 `MaterialApp` 用 `AppMotion.long` + `emphasized` 交叉淡入。
- 预览卡按当前 `brightness` 取色：跟随系统或固定深色时，预览也随之呈现深色配色。
- 持久化：`flutter_secure_storage` 的 `xinli.theme.v1`，存 `{"skin":"...","mode":"..."}`，皮肤与模式一起读写；读失败、解析失败、未知名称一律回落到校园蓝 + 跟随系统，绝不阻塞启动。启动在 `runApp` 之前读取，因此不会先闪一下默认色。

### 11.21 桌面小组件（课表）

一个横向卡片，`systemMedium`（iOS）/ 4×2 格（Android），两边同一套信息与同一套排版。Android 默认 2 格高度（约 160dp）与 iOS medium 对齐；1 格高度装不下三行信息和进度条，会把内容裁掉。

| 位置 | 内容 |
| --- | --- |
| 左列 | 状态（正在上课 / 下一节课 / 今天没课 / 今日课程已结束）+ 第 N 周 |
| 右列第一行 | 课程名（左）· 剩余或距离时间（右，皮肤色） |
| 右列第二行 | 地点 · 老师 |
| 右列第三行 | 时间区间；正在上课时改为进度条（皮肤色） |

- 数据只来自 Flutter：`WidgetSnapshotBuilder` 把当前学期课表算成带生效时间的 JSON 展示序列（状态、标题、副标题、课程起止时间、周次、强调色），覆盖未来七个校园日并设置过期时间，Android 与 iOS 都只负责画，不认识学校的课表格式，因此两端不会走偏，服务端改动也不需要改原生代码。
- 只展示**当天**：今天课上完就显示“今日课程已结束”，未来日期的快照只在当天零点后生效。原生端按时间选取快照，并根据起止时间计算倒计时和进度，不解析学校课表。七天后未重新同步则显示“课表待同步”，不会沿用旧课程。历史学期不影响小组件。
- 同步时机：课表或登录状态变化、切换皮肤、以及前台每分钟一次；内容没变则不重复推送。退出登录时串行清空共享数据，阻止旧的待写入数据恢复；桌面实际重绘时间由系统调度。
- 点击卡片打开 App 并直接进入课表 tab（`xinli.route=schedule`，读取一次即消费）。
- 原生渲染：Android `RemoteViews` + 圆角卡片 drawable（浅色 / 深色两套）+ 15 分钟一次的 `setInexactRepeating` 刷新；iOS WidgetKit `TimelineProvider` 预生成六小时的分钟快照及之后的课程/零点/过期边界，每六小时申请重建，iOS 17 走 `containerBackground`。Android 非精确闹钟会受系统省电策略推迟，不能保证分钟级更新。

- iOS 主 App 和 ClassWidget 都需用包含 `group.com.sayqz.xinliLite` 权限的描述文件签名，不能继续复用旧版不含 App Group 的签名配置。工程已共享同一份 `ios/Runner/WidgetSnapshotStore.swift`。

### 11.23 课前提醒设置（iOS）

- 「我的 → 课前提醒」使用现有顶部毛玻璃弹层，按账号记忆开关，默认关闭，不在启动时请求系统权限。顶部复用 `AccentPanel`，以大号「15 分钟」和主开关突出提前提醒；下面用 `FrostedCard` 分组放灵动岛开关与说明入口。
- 主开关负责普通通知；iOS 26 及以上可开启自动灵动岛。开启前说明挂起/关闭 App 后不能保证按时结束，确认后才启用。
- 主视图只显示一行安排状态与同步图标。最晚课程时间、安排更新时间及工作方式收进「提醒说明」二级弹层；开启确认保留简短的后台结束提示。
- 权限拒绝、预约失败、校历缺失、课表刷新失败按优先级只显示一个行内提示，操作紧跟提示（去设置 / 同步 / 重试），不堆叠多条横幅或重复说明。
- 提醒状态与异常提示出现/消失时，弹层用 `AnimatedSize`、`AppMotion.long` 和 `emphasized` 平滑伸缩，顶端保持不动；动态区域用 `sequentialTransition` 淡入淡出。退场内容不占高度、不响应触摸、不被读屏读取；减少动态效果时立即完成。
- 同一课程优先使用一个提醒来源；历史学期浏览不改变提醒。旧灵动岛测试入口已移除。
